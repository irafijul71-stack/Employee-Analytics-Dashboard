# 👥 Employee Analytics Dashboard

## 📌 Project Overview

The **Employee Analytics Dashboard** is an interactive Power BI project designed to analyze workforce data and provide insights into employee demographics, salary distribution, education levels, job satisfaction, work-life balance, and working experience.

The dashboard provides an easy-to-understand view of key employee metrics while allowing users to interact with the data using multiple filters.

## 🎯 Project Objectives

The main objectives of this project are to:

- Monitor key employee metrics
- Analyze employee distribution by demographic and organizational dimensions
- Compare salary patterns across different levels of working experience
- Understand employee education levels
- Evaluate job satisfaction and work-life balance
- Analyze salary trends over time
- Enable interactive HR analysis through dynamic filters
- Support data-driven workforce analysis

## 🔍 Dashboard Analysis

### 👥 Employee Distribution

The dashboard provides a visual breakdown of the current workforce, making it easier to understand the overall employee composition.

### 🎓 Employee Education Level

Employee education is analyzed across:

- Bachelor
- Master
- College
- Below College
- Doctor

The dashboard makes it easy to compare the number of employees belonging to each education level.

### 😊 Job Satisfaction

Employee job satisfaction is categorized into:

- Very High
- High
- Medium
- Low

This analysis provides a clear view of how employees are distributed across different job satisfaction levels.

### ⚖️ Work-Life Balance

The dashboard analyzes employees across different work-life balance categories:

- Bad
- Best
- Better
- Good

This visualization helps compare the distribution of employees across different work-life balance levels.

## 💰 Salary Analysis

### Salary by Years

The dashboard compares salary across different working-year ranges and employment types.

This helps identify how salary distribution changes based on employee experience and employment classification.

### Salary by Working Years & Gender

The dashboard includes a comparative salary analysis across different working-year groups.

This provides an additional perspective on how salary varies across employee groups and levels of experience.

### Monthly Salary Trend

The monthly salary trend visualization tracks salary values from January through December.

This makes it easier to identify increases, decreases, and variations in salary totals throughout the year.

## 🎛️ Interactive Control Panel

The dashboard includes several interactive slicers that allow users to dynamically filter the analysis.

Available filters include:

- Gender
- Education
- Department
- Business Travel
- Employment Type

These filters allow users to explore specific employee segments and perform more focused analysis.
